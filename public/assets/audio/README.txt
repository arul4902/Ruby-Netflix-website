# RUBISHNA AUDIO ASSETS FOLDER

Place your personal audio files here:

1. Personalized Songify Soundtrack:
   File name: rubi-original.mp3 (or song.mp3)
   Path: public/assets/audio/rubi-original.mp3

2. Favourite Song (Hangova or any personal favourite):
   File name: hangova.mp3 (or favourite.mp3)
   Path: public/assets/audio/hangova.mp3

Supported formats: .mp3, .wav, .m4a, .aac, .ogg

You can also use the in-app "📁 Choose Custom Audio" button directly on the website to select any song file from your computer at any time!
